# Gyanodaya Public School Website

A premium, modern, professional, and fully responsive school website built for **Gyanodaya Public School**, located in **Katra, Muzaffarpur, Bihar, India**. 

This project is designed with a clean educational UI/UX, robust accessibility features, fast performance, and easy content management to represent a modern educational institution.

---

## 🌟 Key Features

* **Professional UI/UX:** Clean white space, professional school-themed color palette, smooth scroll animations, and responsive card layouts.
* **Full Responsiveness:** Optimized for everything from small mobile devices (320px) up to large desktop screens without horizontal scrolling.
* **Light & Dark Mode:** Built-in theme switcher with `localStorage` preference memory.
* **Interactive Lightbox Gallery:** Responsive photo grid featuring click-to-enlarge modal viewing with full keyboard navigation support (`Esc`, `ArrowLeft`, `ArrowRight`).
* **Dynamic Form Validation:** Real-time client-side validation for both the Admission Enquiry and Contact forms.
* **Accessibility Focused:** Semantic HTML5, visible focus states, ARIA attributes, and full support for `prefers-reduced-motion`.
* **Performance Optimized:** Uses lazy-loaded responsive `<img>` elements to guarantee zero layout shifts and fast load speeds.
